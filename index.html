Clave de API de Google
¿Cómo consigo la clave? (2 minutos, una sola vez)
  1. Entra a console.cloud.google.com y crea un proyecto cualquiera.
  2. Busca Google Drive API arriba y toca Habilitar.
  3. Vuelve a Credenciales → Crear credenciales → Clave de API.
  4. Copia la clave y pégala aquí. Se guarda en este dispositivo.

Y la carpeta de Drive debe estar compartida como Cualquier persona con el enlace (solo lectura).
